# 02_python_libraries

- **Goal:** Try the main Python libraries for bioinformatics.
- **Data:** Small practice table hits.tsv (5 made-up BLAST rows).
- **What I did:** Used NumPy, pandas, seaborn and matplotlib on a small table.
- **Result:** log2fc.png shows BRCA1 up (log2FC 0.85) and TP53 slightly down (-0.07). pident.png shows 3 hits after filtering, with 92-99% identity.
- **Files:** notebooks/ (my demo notebook and hits.tsv), results/ (figures)
- **How to run:** source ~/bioinfo/venv/bin/activate, then open notebooks/libraries_demo.ipynb in VS Code and press Run All.
