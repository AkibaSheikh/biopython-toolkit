# 04_sequence_analysis

- **Goal:** Compare two sequences with global and local alignment in Biopython.
- **Data:** Two short example DNA sequences.
- **What I did:** Ran global and local pairwise alignments with PairwiseAligner.
- **Result:** Global score 12.0; local score 13.0 (local skips the poorly matching start).
- **Files:** scripts/ (code), results/ (small tables and figures)
- **How to run:** python scripts/alignment_motifs.py
